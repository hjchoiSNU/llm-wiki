# Melanocortin system

## 구성
1. **POMC** (precursor) → enzymatic processing → α-MSH, β-MSH, γ-MSH, ACTH, β-endorphin.
2. **MC1R–MC5R** (G protein-coupled receptors).
   - MC1R = 피부 melanocyte.
   - **[[concept-mc3r|MC3R]]**·[[concept-mc4r|MC4R]] = 식이·EE 핵심. MC3R = rheostat/boundary, MC4R = sustained driver ([[seiler-2026-dual-activation-of-mc3r-and|Seiler 2026]]).
   - MC2R = adrenal cortex (ACTH receptor).
3. **AgRP** = MC3R/MC4R **inverse agonist** (전형).
4. **Agouti** = 피부 MC1R 길항.

## 회로
- ARC POMC → α-MSH → PVN·DMN·LHA MC4R → 식이 ↓ + EE ↑.
- ARC AgRP → MC4R 차단 + GABA·NPY → 식이 ↑.
- 두 집단 상호 길항 + 인근 BNC2 (Tan HL 2024) 보조.

## 인간 단일유전자 비만 (★)
- **MC4R** 변이 가장 흔 (~5% 중증 조기 비만, Farooqi 2003 NEJM).
- **POMC** 변이 (희귀): 비만 + 부신부전 + 붉은 머리카락 (Krude 1998).
- **PCSK1** (PC1/3): POMC processing 효소 결손 (Jackson 1997, O'Rahilly 1995).
- **LEPR** (Clément 1998).

## Setmelanotide
- MC4R full agonist.
- POMC·LEPR·PCSK1·BBS 결핍 환자 임상 승인.
- EE 6.4% ↑ (Chen 2015), 일반 비만에 약함 (회로 보존 환자만).

## Heterogeneity (재정의)
- POMC subset (LepR·InsR·GLP1R·Drd2·5HT2C·CB1R·**Ghost POMC**) — [[jouque-2025-beyond-satiety-unraveling-the|Jouque 2025]].
- AgRP subset (ARC·**Hindbrain**·Pituitary·Adrenal) — [[faour-2025-emerging-role-of-agrp|Faour 2025]].
- MC4R subset = PVN·DMN·LHA·NTS·DMV·IML·spinal V2a 각자 다른 기능.

## De Solis 2024 model
- 식이 = AgRP **활성 + POMC 억제 동시** + PVN^Npy1R → NTS^Th+.
- Insulin·gluconeogenesis는 segregated autonomic branch.

## 발달
- POMC progenitor → POMC·AgRP·Kiss1 ploidy fate (Padilla 2010, Sanz 2015).
- Postnatal leptin surge → projection 발달 (Bouret 2004).
- 모체 비만 = NPY:POMC ratio 변화 + Ascl1 ↓ + epigenetic remodeling.
