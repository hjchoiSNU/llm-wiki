# GLP-1R Signaling and Functional Molecules in Incretin Therapy (Wan 2023)

## 한 줄 요약
GLP-1R 구조·세포내 신호(Gαs/cAMP, Gαq, β-arrestin)·trafficking을 정리하고, 임상 각 단계 incretin 기능분자(peptide mono/multi-agonist, small-molecule agonist·PAM)와 차세대 설계 전략을 개관한 Molecules 2023 리뷰.

## 핵심 내용
- **구조**: class B1 GPCR, 큰 ECD + 7-TM. "two-domain" 결합. native GLP-1은 DPP-4로 t½ ~2분.
- **신호(β세포)**: **Gαs/cAMP**(주경로) → PKA·Epac2 → 인슐린 분비; **Gαq** → PLC/PKC/Ca²⁺; **β-arrestin**(1=생존, 2=인슐린 조절 필수) + internalization·desensitization. Gαs↔Gαq 스위치가 basal 분비 설명.
- **기능분자**: peptide mono(exenatide·liraglutide·semaglutide 등; 안정화=DPP-4저항 치환·acylation·Fc/albumin fusion), multi(**tirzepatide** GIP/GLP-1 최초 승인, cotadutide GCG/GLP-1, 삼중), small-molecule/PAM(danuglipron·**LY3502970=β-arrestin 없는 biased agonist** — 미승인).
- **부작용·최적화**: nausea/vomiting/diarrhea(순응도↓). 최적화 = **G-protein biased agonism**(desensitization↓·표면유지↑·혈당강하↑) + **뇌 침투 조절**(corrination으로 구역 분리) + 경구화(SNAC).
