> [!takeaway] 연구 방향 관점의 핵심
> 미주신경 구심성 뉴런(VAN)이 **gut-brain 통신의 1차 conduit**. Mechanosensors (stretch) + chemosensors (영양소·호르몬·미생물 대사물) 다양한 subtype이 식이의 3 phases 모두 조절. **3-stage 비만 진행** ([[de-lartigue-2026-critical-role-gut-brain-signalling|de Lartigue, Brierley, Choi 2026 NRGH]]): reinforcement-driven → compensatory (vagal 보호) → vagal dysfunction (돌이킬 수 없는 단계). GLP-1RA는 vagus 우회 → 근본 dysfunction 미해결. taVNS·microbiota 개입이 차세대 표적.

# Vagal afferent neurons (VANs)

## 정의
미주신경 (vagus nerve)의 sensory (afferent) 뉴런. Cell body는 **nodose ganglia**에 위치, 말단이 위장관·간·췌장·심장·폐 등에 분포. 중추 종착은 brainstem **NTS** (nucleus of the solitary tract) + **area postrema** (AP).

## 분자 다양성

Single-cell transcriptomics (Kupari 2019, Bai 2019, Zhao 2022)로 ~30+ subpopulation 식별. 식이 관련 핵심:

### Mechanosensors (stretch/tension)
- **Glp1r⁺**: gastric stretch 감지 (Williams 2016). 활성 시 식이 억제 (Brierley 2021).
- **Oxtr⁺**: distension-sensitive. 활성 시 ARC AgRP 빠르게 억제 → **장기 satiety** (Bai 2019, Scott 2025).
- **IGLE** (intraganglionic laminar endings, myenteric plexus): stretch.
- **IMA** (intramuscular arrays, gastric muscle): tension.

### Chemosensors
| Subset | 부위 | 자극원 |
|---|---|---|
| **Sst⁺·Gpr65⁺** | pyloric antrum | 광범위 luminal 자극 (osmosensing 후보) |
| **Calca⁺** | corpus | 미정 |
| **Vip⁺·Uts2b⁺** | intestinal villi | **당·지방·아미노산 generalist**(CCK-의존); post-oral 선호 형성 ([[li-2022-gut-brain-circuits-for-fat-preference\|Li 2022]]) |
| **Cckar⁺** (2 cluster) | hepatic portal·duodenum | sugar/fat reinforcement (McDougle 2024) |
| **TRPA1⁺** subset | | **fat-only**(CCK-비의존) 지방 선호 매개 ([[li-2022-gut-brain-circuits-for-fat-preference\|Li 2022]]) |

영양소 수용체 (Table 4 of [[steinert-2017-ghrelin-cck-glp-1-pyy-secretory|Steinert 2017]]): FFAR1/4, CD36, CASR, LPAR5, GPR119, T1R, SLC5A1, SLC15A1.

## 4가지 signaling 모드 (Steinert 2017 Figure 3)

상세는 [[concept-enteroendocrine-cells]]:
1. Endocrine — 혈류 매개
2. **Neurocrine** — VAN을 lamina propria에서 직접 자극
3. Paracrine
4. **Neuropod** (Bohórquez & Liddle 2014; Kaelberer 2018) — EEC가 VAN과 synapse-like, glutamate 직접 전달, sub-second

## 식이 3 phases 매개 ([[de-lartigue-2026-critical-role-gut-brain-signalling|de Lartigue 2026 NRGH]])

| Phase | VAN 역할 |
|---|---|
| **Food seeking** | Cckar⁺ → DA reinforcement (post-ingestive value); ghrelin via VAN → motivation; gut-hippocampus 메모리 (Yang 2025) |
| **Food consumption** | Glp1r⁺·Oxtr⁺ mechano → satiation; chemosensors → 영양소 종류 인식 |
| **Non-prandial activity** | Oxtr⁺ 장기 AgRP 억제; circadian gating (Woodie 2024) |

## 3-stage Diet-Induced Obesity progression (NRGH 2026 Box 3)

| Stage | VAN 변화 | 표현형 |
|---|---|---|
| **1. Reinforcement-driven** | chemosensory → DA reinforcement 활발 | 칼로리 dense food 선호 ↑, 정상 BW |
| **2. Compensatory** | mechano + ileal brake + leptin·CCK reprogramming | meal size ↓ → kcal titration → **VAN이 비만 방어** |
| **3. Vagal dysfunction** | sensitivity ↓, NTS terminal remodelling, gene 변화 (CART ↓, leptin resistance) | 과식, weight gain, **돌이킬 수 없는 시점 가능** |

→ Stage 2→3 전이가 **개입의 critical inflexion point**.

## 핵심 발견

### Compensatory mechanisms (Stage 2)
- **Ileal brake**: 미흡수 영양소 → ileum L-cell GLP-1·PYY → 위 이완·distension ↑ → mechanosensor → satiation.
- **CCK + leptin synergy**: vagal mechanosensor 민감도 ↑ (Barrachina 1997).
- **Neurochemical reprogramming**: leptin이 VAN의 satiety receptor·neuropeptide 발현 ↑, orexigenic ↓ (de Lartigue 2014).

### Stage 3 vagal dysfunction
- **Sensitivity ↓** (Daly 2011, Kentish 2012).
- **Terminal remodelling**: NTS vagal fibre 밀도 ↓ 3주 내 (Vaughn 2017); 8주 후 부분 회복하나 기능 미회복.
- **Microbiota 매개** (Sen 2017, Kim 2020): high-fat 유도 dysbiosis → vagal remodelling. Lean donor FMT → 회복 (Minaya 2024).
- **Leptin resistance** in VAN (de Lartigue 2011, 2012).
- **CART ↓** → meal size ↑ (Lee 2020).
- 일부 변화는 weight loss 후에도 지속 → relapse 취약.

## VAN → primary reward (sugar/fat) 회로 ★

[[grove-2025-lateralized-pathway-associating-nutrients|Grove 2025 bioRxiv]]가 분자 정체 규명한 reinforcement 회로:

```
[Sugar]   SGLT1 (intestinal) → vagal → nodose →                
                                              → hindbrain → VTA-DA-CCK → left aBLA D1R
[Fat]     GPR40/120 + CD36 (intestinal) → vagal → nodose →    
```

- **Sugar/fat의 [[concept-flavor-nutrient-conditioning|flavor-nutrient conditioning]]을 직접 매개**.
- 평행 (parallel) but **distinct subpopulations** in nodose (McDougle 2024).
- **지방 선호의 두 병렬 미주 경로** ([[li-2022-gut-brain-circuits-for-fat-preference|Li 2022, Zuker lab]]): ① **VIP⁺(UTS2b) generalist**(당·지방·아미노산, CCK-의존, [[concept-free-fatty-acid-receptors|GPR40/GPR120]]) + ② **TRPA1⁺ fat-only**(CCK-비의존). 미각 비의존 gut-brain 지방 wanting.
- Sugar+fat **supra-additive** primary reward — 비만 음식의 강화 메커니즘.
- 좌·우 vagus 비대칭 가능성 (de Araujo 2023 bioRxiv) → BLA lateralization origin 후보.

[[weber-2025-interoceptive-origin-reinforcement-learning|Weber 2025]]: VAN은 **post-oral primary reward 신호의 1차 신경 channel** — RL framework에 직접 통합. Hepatoportal vein의 glucose oxidation sensor (Zhang 2018) + upper intestine sensor가 이 channel의 시작.

[[knight-liberles-2025-interoception|Knight & Liberles 2025]]의 themed issue가 vagal afferent 분야의 2025 frontier 정의 — Berthold review가 위·장 vagal 직접 갱신, Gribble이 EEC chemosensor 분자.

## 임상

- **GLP-1RA**는 vagus 우회 → 근본 dysfunction 미해결, 중단 시 weight regain.
- **Bariatric surgery** (RYGB)가 vagal function 일부 회복 (Ballsmider 2015) → 장기 효과 가설.
- **taVNS** (transcutaneous auricular vagus stimulation): 만복 시 음식 'liking' ↓ (Salaris 2025) — 차세대 electroceutical ([[lee-2025-hijacked-brain-modern-obesity-cue|JOMES 2025]]).
- **Microbiota 개입**: prebiotics·FMT로 vagal 회복 가능성.
- **VBLOC** (vagal blocking) 임상 device (Camilleri 2008).
