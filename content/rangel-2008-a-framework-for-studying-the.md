# A framework for studying the neurobiology of value-based decision making (Rangel 2008)

## 한 줄 요약
신경경제학(neuroeconomics)의 공통 어휘를 세운 리뷰: 가치 기반 의사결정을 **5가지 계산**(표상·가치평가·행동선택·결과평가·학습)으로 나누고, 가치평가가 **세 시스템(Pavlovian·습관·목표지향)** 에서 따로 일어나며, **조절변수(위험·지연·사회 맥락)** 가 각 시스템의 가치를 바꾼다는 틀을 제안했다. 시스템 간 충돌과 통제권 배정 실패를 OCD·과식·중독 같은 의사결정 병리의 설명 후보로 놓고 **계산정신의학**으로의 확장을 예고한다 (Nat Rev Neurosci 2008; Caltech Rangel·Camerer, Baylor Montague).

> 📌 성격: 2008년 시점의 **개념 틀·어휘 정리**다. 섭식·과식 사례는 대부분 **예시**이고 과식을 직접 실험한 데이터가 아니다. 저자들 스스로 세 시스템의 신경 기반은 "아직 확립되지 않았고 완전히 분리된 신경계에 대응하지 않을 수 있다"고 단서를 단다.

## 핵심 내용

### 1. 틀의 세 구성요소
1. 의사결정 계산을 **5가지 과정**으로 분해한다(Fig. 1).
2. 가치평가 시스템은 **여러 종류**다.
3. **조절변수**가 각 가치평가 과정에 다르게 작용한다.

배경 문제의식: 문헌이 'reward'와 'value'를 한정어 없이 써서 서로 다른 계산을 같은 단어로 부르는 혼란이 생겼다 → 공통 어휘가 필요하다.

### 2. 다섯 가지 계산 (Fig. 1)

| 단계 | 하는 일 | 2008년 시점 지식 |
|---|---|---|
| **표상 (representation)** | 내부 상태(예: 배고픔 수준)·외부 상태(예: 위협 수준)·가능한 행동 집합을 식별 | 거의 모름 — 어떤 행동을 후보에 넣고 뺄지, 한 번에 몇 개를 고려할 수 있는지, 상태가 어떻게 계산돼 가치평가로 넘어가는지 미상 |
| **가치평가 (valuation)** | 후보 행동마다 가치를 부여(내부·외부 상태 반영) | 세 시스템(아래 §3) |
| **행동선택 (action selection)** | 가치를 비교해 하나를 선택 | 지각 의사결정의 race-to-barrier diffusion 모델뿐; 가치 기반·다중 선택으로의 확장 미상 |
| **결과평가 (outcome evaluation)** | 실행 뒤 결과가 얼마나 바람직했는지 측정 | 내측 OFC 등(§6) |
| **학습 (learning)** | 결과평가로 위 과정들을 갱신 | 습관계의 강화학습이 가장 잘 이해됨(§7) |

- 단계는 엄격한 순서가 아니다 — 가치평가가 행동선택보다 먼저인지, 병렬인지도 모른다.
- 틀이 내놓는 검증 가능한 예측: 뇌는 **선택 시점의 가치 신호와 결과 시점의 가치 신호를 따로** 부호화해야 하고, **고려 중인 모든 행동에 대해** 가치 신호를 계산해야 한다.

### 3. 세 가치평가 시스템 ★

| | **Pavlovian** | **습관 (habitual)** | **목표지향 (goal-directed)** |
|---|---|---|---|
| 가치를 매기는 대상 | 특정 자극에 대한 **소수의 진화적으로 '준비된' 반응**(접근·소비·회피) | **자극(상태)–반응** 연합 — 반복 훈련으로 매우 많은 행동에 부여 가능 | **행동–결과** 연합을 계산한 뒤 결과의 보상을 평가 |
| 학습 | 다수는 선천적(hard-wired)이나 훈련으로 새 자극에 배치 가능(먹이를 예고하는 빛에 접근) | 시행착오, **느림** → 유관성이 바뀐 직후에는 가치를 틀리게 예측; 새 상황에서는 **일반화**로 가치 부여 | 결과 가치가 바뀌면 **즉시** 행동 가치를 갱신 |
| 현재 상태와의 관계 | 손 닿는 음식의 소비 행동에 **배고픔 상태와 무관하게** 높은 가치(Box 1) | **그날의 필요와 무관하게** 높은 가치(Box 1) | 현재 결과 가치에 민감 |
| 포만 후 지렛대 누르기 예 | — | 포만 전 훈련 때 배운 **높은 가치 유지** | 음식의 현재 가치(낮음)만큼 **낮은 가치** |
| 신경 기반(논문 정리) | 편도·배쪽 선조체·OFC 연결망이 중립 자극→결과 가치 예측 학습. **CeA**(→뇌간·NAc core) = 비특이적 준비 반응, **기저외측 복합체**(→시상하부·PAG) = 더 특이적 반응. 혐오 자극의 능동·수동 반응은 dPAG 축을 따라 조직 | **배외측 선조체(DLS)** 와 그곳으로의 도파민 투사(행동 가치 학습), 피질–시상 루프(S-R 표상), **변연하 피질(infralimbic)** — 병변 시 습관의 확립·발현 실패 | **배내측 선조체(DMS)** = 행동–결과 학습·표현, **OFC** = 결과–가치; 원숭이·인간에서 OFC·DLPFC의 goal value 신호, 내측 OFC 손상 시 일관된 선호 선택 장애; BLA·내측배쪽 시상(DLPFC와 "연합 피질–기저핵 루프") |
| Box 1의 일상 예 (보상 / 회피) | 접시의 음식을 다 먹는다 / 위험해 보이는 사람을 보고 길을 건넌다 | 아침 커피 한 잔 / 늘 다니는 길로 출근 | 볼 영화 고르기 / **달리기하러 가기(피하는 벌 = 비만)** |
| 그 밖의 예 | 과식(음식이 눈앞에 있을 때), OCD의 행동, 더 큰 지연 보상을 버리고 작은 즉시 보상을 취하는 것 — "Pavlovian계가 통제할 수 있다"는 저자 제안 | 흡연자가 하루 중 특정 시점(예: **식후**)에 담배를 원함; 충분히 훈련된 랫의 cue 의존적 장소 탐색 | 처음 가는 식당에서 메뉴 정하기 |
| 저자들이 남긴 질문 | Pavlovian계가 몇 개인가; 공통의 가치 운반자가 있는가; 계 안에서 학습이 되는가; PIT 같은 현상에서 다른 계와 어떻게 상호작용하는가 | 습관계가 여럿인가; 지연 보상·위험을 어떻게 평가하는가; 얼마나 복잡한 환경까지 감당하는가; **한 상태에서 다른 상태로(예: 배고픔→갈증) 얼마나 일반화하는가** | 보상/처벌·목표 종류별로 특화된 계가 있는가; 행동–결과 연합은 어떻게 학습·활성화되는가; 낯선 결과의 가치는 어떻게 매기는가 |

- **Pavlovian 반응도 '가치'를 갖는다는 논리**: 자동 반응처럼 보이지만 다른 시스템이 끼어들어 중단시킬 수 있으므로, 다른 계가 선호하는 행동과 **경쟁할 수 있는 가치 같은 것**이 부여돼 있어야 한다.
- **목표지향계의 한계**: 평가의 질이 **행동–결과 연합의 질**에 묶인다. 복잡한 경제적 선택에서는 인간의 명제 논리(propositional logic) 시스템이 연합을 구성해 목표지향계에 넘겨준다는 추측.
- **열린 쟁점**: 시스템이 셋보다 많은가(Lengyel & Dayan의 '일화적(episodic)' 시스템 제안); 장기 목표·문화 규범·도덕은 어떻게 가치평가에 들어오는가 — 한 가지 가능성은 습관계·목표지향계가 **규범 위반을 혐오적 결과, 준수를 보상적 결과**로 취급하는 것.
- **다이어터 예**: 파티에서 맛있는 디저트를 권받는 것은 새로운 상황이라 목표지향계가 평가할 가능성이 크고, 이때의 갈등은 **즉각적 맛 보상을 평가하는 목표지향계와 장기 결과를 평가하는 목표지향계** 사이의 충돌일 수 있다(같은 유형의 시스템이 둘 이상일 가능성).

### 4. 조절변수 — 위험과 지연 (목표지향계 중심)

**위험·불확실성 (Box 2)**
- 두 견해: (a) 기댓값·분산·왜도 같은 **통계적 모멘트**를 따로 계산해 합친다(금융경제학·행동생태학), (b) **기대효용(EU)** 또는 **전망이론(PT)** 식으로 결과별 효용에 확률 가중을 곱한다. 행동 자료만으로는 구분이 어렵다.
- PT의 가정: 준거점 기준 평가, 이득에 오목·손실에 볼록, **손실 회피**, 작은 확률 과대가중·큰 확률 과소가중.
- 인간 fMRI: 기댓값 신호 — 선조체·내측 OFC / 위험(분산) 신호 — 선조체·섬엽·외측 OFC / PT형 가치 신호 — 배쪽·등쪽 선조체, 복내측·복외측 전전두, ACC, 일부 중뇌 도파민 영역. 모호성(ambiguity, 확률 일부 미지) — 편도·OFC·전측 섬엽 예비 근거.
- 편도 손상 환자는 **잠재 이득**이 걸린 결정에서만 나쁜 선택(손실은 아님) → 이득/손실 평가에서 편도의 비대칭 역할 시사.
- **Pavlovian·습관계에서 위험이 가치에 어떻게 반영되는지는 거의 모른다.** 대부분의 강화학습 모델은 습관 학습계가 기댓값만 담고 위험은 담지 않는다고 가정하지만 충분히 검증되지 않았다. 습관계와 목표지향계가 확률을 **다르게 학습해 다른 확률 가중**을 보인다는 행동 근거가 있다.

**시간 할인 (Box 3)**
- 쌍곡(hyperbolic) 할인 `1/(1+kt)` vs 지수(exponential) 할인 `γ^t`. 목표지향 행동의 비교 연구에서는 쌍곡이 더 잘 맞지만, 지수 할인만이 **동적 일관성**(평가 시점이 바뀌어도 선호 순서 유지)을 만족한다. 쌍곡 할인은 평가 시점에 따라 선호가 뒤집힌다(동적 비일관성).
- 신경 근거의 두 진영: 할인율이 다른 **두 시스템**의 상호작용(McClure 2004) vs **단일 가치평가 시스템**(Kable & Glimcher 2007). 화해 가설: 선조체–전전두 연결망이 다른 곳의 정보를 하나의 가치 신호로 통합하되, 즉시 보상은 '즉시성 표지'를 켜서 가치 신호를 키운다.
- 목표지향계와 습관계 모두 지연 보상에 낮은 가치를 준다는 것은 확립됐으나, **Pavlovian계와 습관계의 할인 특성은 인간에서 체계적으로 연구되지 않았다**. 할인율은 문제의 표현 방식·보상을 떠올리는 방식·**각성 수준** 같은 맥락에 크게 좌우된다.

### 5. 행동선택 — 시스템 간 충돌과 통제권 배정 ★
- 세 시스템은 **대개 일치**한다(식사 때 배고프면 셋 다 음식 소비에 높은 가치). 문제는 충돌할 때다(Fig. 2).

| 충돌 | 논문의 예 | 각 시스템의 가치 |
|---|---|---|
| Pavlovian ↔ Pavlovian | 배고픈 동물에게 음식과 전기충격을 동시에 제시 | 접근계: 음식↑·도피↓ / 회피계: 도피↑·음식↓ |
| Pavlovian ↔ 습관 | **음식에서 달아나면** 보상받도록 훈련된 동물 | Pavlovian: 음식 쪽으로 달리기↑ / 회피 습관: 음식에서 달아나기↑ |
| **Pavlovian ↔ 목표지향** | **배부른데 한 입 더 먹을지** 고민하는 사람 | Pavlovian: 음식↑ / 건강 목표지향계: 음식↓ |
| 습관 ↔ 습관 | 소리엔 지렛대 접근·빛엔 회피를 배운 동물에게 둘을 동시 제시 | 접근 습관↑ / 회피 습관↑ |
| **습관 ↔ 목표지향** | 술집에서 한잔할지 고민하는 알코올 중독자 | 습관: 술↑ / 회피 목표지향계: 술↓ |
| **목표지향 ↔ 목표지향** | 아이스크림을 먹을지 고민하는 다이어터 | 맛 목표지향계↑ / 회피 목표지향계↓ |

- **중재 이론**(실험 근거는 당시 희박):
  - Daw 등(2005): 뇌는 **행동의 참 가치를 덜 불확실하게 추정하는 시스템**에 통제권을 준다. 습관계 추정의 질은 경험이 쌓일수록 좋아지므로 **습관계가 목표지향계를 점차 대체**한다.
  - Frank: 보상성·혐오성 습관 가치 사이의 선택을 다루는 신경망 모델.
- **통제권 배정이 중요한 세 이유**:
  1. 겉보기에 이해하기 어려운 행동 다수가 시스템 간 충돌의 산물일 수 있다(Dayan 등 2006).
  2. 의사결정의 질은 **가치 예측이 가장 좋은 시스템에 통제권을 주는 능력**에 달려 있다 — 익숙한 상황에서는 습관계에 주는 것이 최적이지만 **빠르게 변하는 환경에서는 아니다**.
  3. 일부 의사결정 병리(예: **OCD·과식**)는 적절한 시스템에 통제권을 주지 못하는 것("an inability to assign control to the appropriate system")에서 올 수 있다.
- 남은 질문: 중재의 신경 기전; 통제기 사이에 **위계**가 있는가(Pavlovian이 목표지향보다 우선하는가); 목표지향/습관 통제를 **식별할 신경 표지**가 있는가; 목표지향 결정은 결과끼리 비교하는가 행동끼리 비교하는가.

### 6. 결과평가
- 인간 fMRI: **내측 OFC** 활동이 보상을 즐기는 시점의 주관적 쾌 보고와 상관(후각·미각·음악), **포만까지 먹인 뒤의 결과 가치 감소**와 평행, 금전 같은 2차 강화물에도 반응. 통증 강도는 섬엽·ACC.
- 원숭이: 배측 ACC의 결과 가치 신호. 랫: **NAc와 배쪽 창백의 일부를 오피오이드 작용제로 활성화하면 'liking' 표현(혀 내밀기)이 증가**하고, 그 뒤 **작용제와 짝지어진 보상을 더 많이 섭취** — 결과평가 신호가 학습에 쓰인다는 가설과 일치.
- **신념이 결과 가치를 바꾼다**: 같은 냄새를 체다 치즈라고 믿는지 땀에 젖은 양말이라고 믿는지, 와인 가격, 음료 상표에 대한 믿음에 따라 내측 OFC의 결과평가 반응이 달라진다.
- 미해결: 영역(domain)별 긍정·부정 결과 가치의 계산망, 두 신호의 통합, 학습 과정으로의 전달 방식, 장기 목표·규범에 의한 조절.

### 7. 학습 — 습관계의 강화학습
- 가장 잘 이해된 것은 **습관계의 행동 가치 학습**. 모든 선택 뒤 **예측 오차(prediction error)** 를 계산해 행동 가치를 그에 비례해 바꾼다.
- Box 4: Markov 결정 문제에서 Q-학습 — `δ = r + γ·max Q(s′,a′) − Q(s,a)`, `Q ← Q + η·δ`. 변형으로 SARSA·actor–critic. 공통 성질: **model-free**(전이·보상 함수를 모른다고 가정), blocking·overshadowing·억제 조건화 설명, 계산이 단순(긴 보상 이력을 추적할 필요 없음).
- 중뇌 도파민 뉴런의 예측 오차 유사 신호(Schultz), 강화학습 모델과의 연결(Montague 등 1990년대), 인간 배쪽 선조체 BOLD와 예측 오차의 상관.
- 2008년의 열린 문제: **음의 예측 오차**는 누가 부호화하는가(도파민 위상성 발화는 양의 성분만 담을 수 있다는 자료; 발화–휴지 타이밍 설; 도파민=양·세로토닌=음의 대립 가설); 도파민 뉴런이 보상 크기 범위에 맞춰 발화를 조정하는 현상(표준 예측 오차 해석과 불일치); 선택하지 않은 행동의 결과로부터 배우는 **fictive learning**.
- **Pavlovian계와 목표지향계가 가치를 갱신하는 알고리즘은 알려져 있지 않다.** 그 밖의 질문: credit assignment가 복잡하고 보상이 지연될 때 습관계의 한계; **습관계가 내부·외부 상태를 가치에 넣고 상태 간 일반화하는 법**; 관찰 학습.

### 8. 계산정신의학과 "향후 5년" (Box 5)
- 강화학습 모델은 약물·질병·발달 사건이 **행동이나 정신 상태에 적절한 가치를 부여하는 능력을 교란**하는 '가치평가 기능 이상'을 예측한다. Redish(2004)는 중독을 **습관 가치평가계의 질병**으로 강화학습 모델의 단순한 수정만으로 개념화했다(주석 달린 참고문헌).
- 의사결정 장애는 **행동선택 단계**, 특히 가치계 간 충돌에서도 생길 수 있다 → **정량화 가능한 새 정신질환 분류**의 가능성. 이 문제는 '의지(will)'를 어떻게 볼 것인가와 닿아 있고 **중독·OCD·비만**에 적용된다.
- 동기(motivation: 보상을 얻으려 얼마나 열심히 일하는가)의 장애는 우울 같은 기분장애와 파킨슨병에서 중요할 수 있다.
- 낙관 근거: 이론 주도 실험, 자유행동 동물의 fast cyclic voltammetry(준실시간 신경전달물질 측정), 다종·다기법 접근.
- 응용 전망: 정신의학, 사법(의사결정 능력 판단), **자기통제 실패(중독·비만·저축)에 대한 공공정책**, 마케팅 규제, 인공지능, 고압 상황 의사결정 훈련.

## 습관적 과식 관점의 강화 정리 ★
> 이 절은 논문 내용을 위키의 다른 페이지와 맞물린 **위키 차원의 정리**다. 논문 자체의 진술은 "논문:"으로, 위키의 연결·해석은 "위키 해석:"으로 구분한다.

### A. 논문이 섭식·과식을 직접 언급한 대목 (전수)
1. **Pavlovian계가 통제할 수 있는 행동**의 예로 "음식이 눈앞에 있을 때의 과식"을 OCD 행동·즉시 보상 선호와 함께 든다(§Pavlovian systems).
2. **Box 1**: Pavlovian 보상 예 = 접시의 음식을 다 먹는다. 손 닿는 음식을 먹는 소비 행동은 **배고픔 상태와 무관하게** Pavlovian계가 높은 가치를 준다. 목표지향 회피 예 = 달리기(피하는 벌: 비만).
3. **습관의 예**: 흡연자의 식후 담배. 음식 자체에 대한 습관 예는 랫의 cue 의존 탐색뿐이다.
4. **목표지향의 예**: 새 식당에서의 메뉴 결정; 포만 후 지렛대 누르기(devaluation) 사고실험.
5. **Fig. 2 충돌**: 배부른데 한 입 더(Pavlovian↔목표지향), 다이어터의 아이스크림(목표지향↔목표지향).
6. **통제권 배정 실패 가설**: OCD와 과식.
7. **결과평가**: 포만 후 내측 OFC 결과 가치 감소; 오피오이드 'liking' 증폭과 그 뒤 섭취 증가.
8. **표상**: 내부 상태의 예로 배고픔 수준; 습관계 질문으로 "배고픔→갈증" 일반화.
9. **Box 5·결론**: 비만을 계산정신의학과 자기통제 정책의 적용 대상으로 명시.

### B. "과식"의 세 가지 가치계 버전 — 판별표
위키 해석: 같은 "배고프지 않은데 먹는다"도 어느 가치계가 미는지에 따라 측정·개입이 달라진다.

| | **Pavlovian 과식** | **습관적 과식** | **목표지향 과식** |
|---|---|---|---|
| 방아쇠 | **음식 자체 또는 음식 cue의 존재** | **상태·맥락·시간**(책상, TV, 오후 3시) — 음식이 눈앞에 없어도 찾아 나선다 | 결과에 대한 **기대·신념**(맛, 위안, "오늘은 괜찮아") |
| 논문의 예 | 접시 비우기, 배부른데 한 입 더 | (음식 예 없음) 아침 커피·식후 담배·술집의 알코올 중독자 | 파티 디저트·아이스크림 앞의 다이어터 |
| 조작적 판별 | 음식·cue 제거 시 소실; PIT; 조건화 접근 | **outcome devaluation·contingency degradation에 둔감**한 도구 행동 | devaluation에 민감; 가격·신념·대안에 따라 선택이 바뀜 |
| 위키의 회로 근거 | [[derman-2018-junk-food-enhances-conditioned-food-cup\|Derman 2018]](정크푸드가 조건화 접근만 강화), [[odoherty-2016-multiple-systems-for-the-motivational\|O'Doherty 2016]](specific PIT는 devaluation 둔감), [[pascoli-2026-conditioned-accumbal-dopamine-transients\|Pascoli 2026]], [[concept-cue-reactivity]] | [[giovanniello-2025-a-dual-pathway-architecture-for\|Giovanniello 2025]], [[hobel-2026-a-basolateral-amygdala-to-dorsolateral\|Hobel 2026]], [[piette-2026-striatal-endocannabinoids-drive-one-shot\|Piette 2026]] — [[concept-habit]] 경로 A–D | [[hoang-2026-methamphetamine-potentiates-the-use-of\|Hoang 2026]](cue 통제가 결과 표상을 담는다), [[concept-inhibitory-control-demand]], [[concept-goal-commitment]] |
| [[lee-2025-hijacked-brain-modern-obesity-cue\|Hijacked Brain]] 대응 | **Cue형** | **Habit형** | **Restraint형**(목표지향↔목표지향, Pavlovian↔목표지향 충돌) |

- 위키 해석: Hijacked Brain의 **Addiction형**은 논문의 "습관↔목표지향"(알코올 중독자) 및 Redish(2004)의 "습관 가치계의 질병"에 가깝다. **Emotion형은 이 틀에 직접 대응 항목이 없다** — 논문의 조절변수는 위험·지연·사회 맥락이고, 정서·스트레스는 각성이 할인율을 바꾼다는 언급 정도다. 그 빈칸을 이후 위키 근거가 채운다(스트레스가 통제권을 습관 쪽으로 넘긴다: [[giovanniello-2025-a-dual-pathway-architecture-for|Giovanniello 2025]]; 편도가 DLS의 S-R을 증폭: [[hobel-2026-a-basolateral-amygdala-to-dorsolateral|Hobel 2026]]).
- ⚠️ 논문의 Pavlovian 설명("소수의 준비된 반응")과 달리, 위키의 [[hoang-2026-methamphetamine-potentiates-the-use-of|Hoang 2026]]은 Pavlovian cue가 **특정 결과의 표상**을 통해 선택을 바꾼다고 본다 → Pavlovian 과식 안에서도 "반사적 소비"와 "결과 표상을 통한 선택 왜곡"을 나눠야 한다.

### C. 5단계 계산으로 본 습관적 과식의 고장 지점
위키 해석: 각 단계는 "습관적 과식이 어디서 생기는가"에 대한 서로 다른 가설이다.

| 단계 | 습관적 과식에서의 질문 | 위키 근거 |
|---|---|---|
| **표상** | 포만·에너지 상태가 "지금 상태"의 표상에 들어가는가? 습관 가치는 배고픈 상태에서 배운 것을 **배부른 상태로 그대로 일반화**하는가(논문의 미해결 질문) | Need 신호의 원천은 [[concept-need-motivation-pleasure-utility\|NMPU]]·[[concept-npy-agrp-neurons]]; 등쪽 선조체 도파민이 과제 내 시간 정보와 다음 섭취 여부를 담는다([[gordon-2026-lateral-hypothalamic-control-of-the\|Gordon 2026]]) |
| **가치평가** | 과식을 미는 가치가 어느 계의 것인가(위 B 표) | [[concept-habit]] §1 |
| **행동선택** | **통제권이 습관계에 머무는가** — 논문이 과식에 직접 건 가설. 익숙하고 안정된 환경에서는 습관계 인계가 정상이므로, 문제는 결과 가치가 바뀌었는데도(포만·건강 목표) 통제권이 재배정되지 않는 것 | 인간 중재자 = vlPFC·frontopolar([[odoherty-2016-multiple-systems-for-the-motivational\|O'Doherty 2016]]); 스트레스가 BLA→DMS를 끄고 CeA→DMS를 켠다([[giovanniello-2025-a-dual-pathway-architecture-for\|Giovanniello 2025]]) |
| **결과평가** | 결과 신호가 약하면 목표지향계가 갱신할 재료가 없다 — 먹어도 좋지 않은데 계속 먹는 상황 | [[concept-hedonic-devaluation]], [[gazit-shimoni-2025-changes-in-neurotensin-signalling-drive\|Gazit Shimoni 2025]], [[concept-liking-wanting]] |
| **학습** | 습관계는 느리게 갱신된다 → 식이·환경이 바뀐 직후 옛 가치로 행동; 지연된(장 이후) 결과의 credit assignment | 등쪽 선조체는 칼로리(post-oral) 가치로 강화된다([[tellez-2016-separate-circuitries-encode-hedonic-nutritional\|Tellez 2016]]); 소거보다 유관성 약화가 cue 도파민을 빨리 낮춘다([[jeong-2022-mesolimbic-dopamine-release-conveys-causal\|Jeong 2022]]·[[concept-anccr]]) |

### E. lab 설계 함의
1. **Habit형 판정 전에 Pavlovian 소비형을 배제한다.** "음식이 있으면 먹는가"(Pavlovian)와 "음식이 없어도 그 시간·장소에서 찾아 먹는가"(도구적 습관)는 다른 문항·다른 과제다. 동물에서는 조건화 접근/PIT와 devaluation 검사를 같은 코호트에 함께 건다.
2. **개입 표적을 '가치'가 아니라 '통제권 배정'에 둔다.** 습관 가치를 지우는 것(소거)과 통제권을 목표지향계로 되돌리는 것은 다른 목표다. 후자는 중재 회로(vlPFC·frontopolar)와 예측 신뢰도 조작이 표적이다(위키 해석; [[concept-digital-therapeutics]]).
3. **Restraint형은 습관이 아니라 목표지향계 내부의 충돌**이라는 [[concept-habit]] §4의 구분을 논문의 다이어터 예가 뒷받침한다.
4. **NMPU 대응**(위키 해석): 표상의 내부 상태 ≈ Need / 가치평가·행동선택 ≈ Motivation / 결과평가 ≈ Pleasure / 학습 ≈ Pleasure·Utility의 교사 기능. 논문은 결과평가를 **즉각과 지연으로 나누지 않는다**(예시로 든 "먹은 음식이 탈을 일으켰는지"는 지연 결과) — Utility를 따로 세운 것이 NMPU의 추가분이다([[kim-2024-unified-theoretical-framework-underlying-regulation|Kim 2024]]).

## 한계·주의
- 2008년 리뷰다. 중재의 실험 근거, 습관·Pavlovian계의 위험·지연 처리 등은 "모른다"로 남겨 둔 항목이 많다.
- 세 시스템 구분은 **계산 방식에 따른 조작적 구분**이며, 저자들은 신경 수준에서 공통 요소를 공유할 가능성을 명시한다.
- 과식·비만 언급은 예시와 전망이고, 과식이 Pavlovian계 문제인지 통제권 배정 문제인지에 대한 **데이터는 없다**.
- 습관계 = model-free 강화학습이라는 등식은 이 리뷰의 전제이지 증명이 아니다.
