> [!takeaway] 연구 방향 관점의 핵심
> PVN = **ARC melanocortin·LepR·GLP-1R first-order의 가장 dense second-order 표적**. MC4R·OXT·CRH·TRH·AVP 뉴런이 식이·생식·HPA·자율신경 통합 hub. **PVN MC4R 회로가 모체 비만 자손의 hypertension** (Samuelsson 2016 PNAS) — 사용자 lab의 비만-cardiovascular 임상 함의 직격.

# Paraventricular nucleus (PVN / PVH)

## 위치
시상하부 3V 양옆 dorsal. ARC와 DMH의 ventral, magnocellular + parvocellular subdivision.

## 주요 cell types
| Type | 기능 |
|---|---|
| **MC4R+** | ARC POMC α-MSH의 핵심 표적. 식이·EE·SNS·BP. |
| **OXT (oxytocin)** | Magnocellular = posterior pituitary 분비. Parvocellular = central projection. Satiety + 사회행동·stress buffering. |
| **CRH** | HPA axis 활성 (anterior pituitary → ACTH). 만성 stress·식이. |
| **TRH / PACAP(Adcyap1)** | Thyroid axis 외에, **글루타메이트성 TRH⁺/PACAP⁺ 소집단이 ARC^AgRP를 흥분→섭식 구동**([[krashes-2014-an-excitatory-paraventricular-nucleus-to\|Krashes 2014]]; PVH=satiety 통설 반전). 그 정제 부분집합이 PVH^Sim2([[walker-2026-a-hypothalamic-circuit-for\|Walker 2026]]). |
| **AVP** | Magnocellular = water balance. |
| **Npy1R+ Glut** | AgRP·POMC 동시 입력 → NTS^Th+ (De Solis 2024 Nat Metab) — 식이의 **single neuron integrator**. **Npy1r=PVH ensemble의 행동상태 conductor** ([[xu-2020-behavioral-state-coding-by\|Xu 2020 Science]]). |
| **BDNF** | An 2015 Cell Metab — 식이·EE 통제 ([[concept-ventromedial-hypothalamus|VMH^BDNF]]보다 작은 sub). |

## 입력
- ARC AgRP (가장 dense ~30% projection).
- ARC POMC (caudal subset → PVN).
- DMH·LH·NTS·VTA loop.
- Sensory cue 즉시 신호 (Chen·Knight 2015).

## 출력
- 뇌하수체 (HPA·HPT·HPG·HPO).
- DMV (parasympathetic) → 위장관·췌장.
- IML (sympathetic) → BAT·WAT·심혈관·신장.
- Brainstem·spinal locomotor 영역.

## 사용자 lab 함의
- **PVN MC4R = 모체 비만 hypertension** 매개 ([[freire-agulleiro-2026-early-life-programming-of|Freire-Agulleiro 2026]]).
- **OXT 회로 손상** → 자손 사회행동 결손 + 비만 [[concept-need-motivation-pleasure-utility|NMPU]]의 social 차원.
- **CRH stress 회로** → [[lee-2025-hijacked-brain-modern-obesity-cue|hijacked brain]] emotional eating type.
- **Npy1R+ → NTS^Th+** = AgRP/POMC integration node — 사용자 lab의 GLP-1·BDNF 회로 연구와 합류.
