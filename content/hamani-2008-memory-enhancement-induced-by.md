# Memory enhancement induced by hypothalamic/fornix DBS (Hamani 2008)

## 한 줄 요약
난치 비만에 복측 시상하부(fornix 인접) DBS를 시도한 환자에서, 자극이 자전적 기억을 유발하고 해마 의존적 회상(recollection)을 선택적으로 증강시킨 단일 사례(Ann Neurol).

## 핵심 내용
- **대상**: 50세 남성, BMI 55.1(190.5 kg). 비만 치료(식욕 조절) 목적의 investigational DBS. 기억 효과는 우연 발견.
- **방법**: 양측 복측 시상하부에 Medtronic 3387 전극(유효 contact은 hypothalamus 내 fornix 근접 추정). on/off 이중맹검 word-pair 재인 과제(Yonelinas/Jacoby로 recollection vs familiarity 분리). 환자 체중으로 PET/MRI 불가 → sLORETA EEG 음원국재.
- **결과**:
  - 자극이 급성·재현적으로 상세한 자전적/déjà vu 기억 유발(역치 3.0 V, 130 Hz, 60 µs; 강도↑에 생생함↑).
  - 인지 재인 "remember" 비율 on 70% vs off 43%.
  - recollection index 0.17(off)→0.38(on); familiarity는 불변 — **회상만 선택적 증강**(12개월 후 재현).
  - 3주 만성 자극 후 California Verbal Learning Test 등 향상.
  - sLORETA: 일측 시상하부 자극이 동측 내측 측두엽(해마·해마방회) 활성↑.
- **안전성**: 수술 당일 전신발작 1회(자극 off, 영상 원인 없음)·흡인성 폐렴. ≥5 V에서 불쾌한 전신 온감·홍조·발한, 최복측 contact에서 시각 phosphene(optic tract 확산). 시험 설정에서 주관적 허기 변화는 재현 안 됨.
- **주장**: fornix 인접 시상하부 자극이 변연계를 구동해 해마 의존적 회상 기억을 선택 증강 — DBS로 인간 기억을 조절할 가능성. (비만/식욕 결과는 본 PDF 본문엔 부재=supplement.)
