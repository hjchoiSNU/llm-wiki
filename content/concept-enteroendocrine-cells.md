> [!takeaway] 연구 방향 관점의 핵심
> **위장관에 산재된 화학감지 호르몬 분비 세포의 패밀리.** 핵심 구조 차이는 **폐쇄형(ghrelin: lumen 노출 X) vs 개방형(CCK·GLP-1·PYY: 미세융모로 lumen 직접 감지)** — 이 차이가 영양소 감지 패러다임을 결정. 그리고 **신경전달-유사 "neuropod"** 분비 모드의 발견은 위장관-신경계 통합 신호 (gut connectome)의 새 패러다임을 열었음.

# Enteroendocrine cells (EEC)

## 정의
GI 상피 (epithelium) 사이에 산재된 단일 호르몬 분비 세포들. 위·소장·대장 전반에 분포. 전체 epithelial cell의 ~1%이지만 신체에서 가장 큰 endocrine organ을 구성.

## 두 구조 타입

### 폐쇄형 (closed-type)
- 정점이 epithelial cell로 둘러싸여 GI lumen 직접 접촉 X.
- 자극 매개체: **혈중 metabolites/hormones**, 신경 신호.
- 대표: **위 oxyntic gland의 ghrelin cell**.
- 함의: lumen 영양소가 직접 자극하지 않음 → 식후 ghrelin 억제는 [[concept-cck|CCK]]·[[concept-pyy-3-36|PYY]] 등 distal hormone, insulin, lactate, SCFA 매개.

### 개방형 (open-type)
- 정점에 미세융모 (microvilli)가 GI lumen으로 노출.
- 영양소를 **apical surface에서 직접 감지** (영양소 수용체).
- 대표: **CCK, GLP-1, PYY, GIP, secretin cells** (소장).

## Historical naming의 한계

| Historical | 가정 호르몬 | 현실 |
|---|---|---|
| **I-cell** | CCK | 다수가 GLP-1, PYY, GIP, ghrelin도 발현 |
| **L-cell** | GLP-1 + PYY (enteroglucagon) | CCK, GIP, neurotensin, secretin도 다수 |
| **K-cell** | GIP | GLP-1, GIP 공발현 다수 |
| **EC-cell** | serotonin | … |

→ 단일 enteroendocrine cell이 **여러 호르몬을 동시 발현·분비**하는 것이 일반적 (Habib 2012, Egerod 2012, Sykaras 2014). Historical naming은 reliable하지 않으며, 분자적 sub-population 분석으로 대체되는 추세.

## 4가지 분비 모드 (Steinert 2017 Figure 3)

```
                Lumen
       ┌─────────────────┐
       │ apical microvilli│ ← 영양소 감지 (개방형만)
       │ (open) /         │
       │ enclosed (closed)│
       └────┬─────────────┘
            │ basolateral 분비
        Lamina propria ─────────────────────
            │       │      │       │
            ▼       ▼      ▼       ▼
        ┌─────┐ ┌──────┐ ┌────┐ ┌──────────┐
        │ ①   │ │ ②    │ │ ③  │ │ ④        │
        │Endo-│ │Neuro-│ │Para│ │Neuropod  │
        │crine│ │crine │ │crine│ │(synapse-│
        │     │ │vagal │ │     │ │ like)   │
        └──┬──┘ └──┬───┘ └─┬──┘ └────┬─────┘
           ▼       ▼        ▼          ▼
        capillary vagal afferent  인접 cell  enteric glia/neuron
        → portal → systemic
```

### 1) Endocrine
Lamina propria → mesenteric capillary → hepatic portal vein → systemic circulation. 가장 희석되는 농도.

### 2) Neurocrine (neuroendocrine)
Lamina propria의 vagal afferent terminal (~5-10 µm 거리)을 직접 자극. 농도가 systemic보다 훨씬 높음.

### 3) Paracrine
인접 epithelial / 다른 enteroendocrine / 면역 세포에 작용. Lamina propria 내 short-range 작용.

### 4) Neuropod (Bohórquez & Liddle 2014)
- Enteroendocrine cell이 **axon-like cytoplasmic extension**을 발달시킴.
- Neuropod 끝이 **enteric glia / 다른 cell과 synapse-like apposition** 형성.
- Pre/postsynaptic protein 발현, **rabies virus 역행성 수송 입증**.
- CCK, PYY cell에서 보고; 다른 EEC에서도 가능.
- 함의: cell-to-cell specific signaling — paracrine보다 한 단계 구체적인 pathway.

## 농도 차이의 함의 — 중요한 방법론적 한계

작용 부위별 호르몬 농도 (대략):
1. Neuropod gap (가장 높음, ~µM 수준 가능)
2. Vagal terminal local (높음)
3. Paracrine in lamina propria
4. Hepatic portal blood
5. **Systemic circulation (가장 낮음, ~pM)**

→ **인간에서 IV infusion이 systemic peak를 재현해도 paracrine·neuropod 농도는 재현 불가**.
→ Paracrine·neuropod 효과는 인간에서 직접 검증 불가능 — animal에서만 가능 (intraintestinal infusion 등).
→ 이것이 ghrelin·PYY 등의 physiological 역할 평가가 어려운 핵심 이유.

## Gut connectome (Bohórquez & Liddle 2015)

- Enteroendocrine cell + ENS (enteric nervous system) + intrinsic GI 뉴런 + 외재 vagal/spinal afferent의 통합 회로.
- "Gut as a sensory organ" 패러다임의 분자적 기반.
- 광유전·DREADD 도구가 vagal afferent 뉴런에 적용되며 빠르게 확장 중.

## 임상/번역적 함의

- **RYGB**가 enteroendocrine cell의 영양소 노출을 극적으로 변경 → 모든 4호르몬 분비 변화 → 대사·식이 효과의 plausible mechanism.
- L-cell density는 distal에서 높음 → distal stimulation 약물 (acarbose, fiber, enteric-coated lauric acid) 또는 BA 매개체가 GLP-1·PYY 증가 전략.
