# Basolateral amygdala (BLA, 기저외측편도체)

## 정의·해부
- 편도체 (amygdala) 의 한 핵 — pyramidal neuron이 우세한 cortex-like 구조.
- Mouse에서 **rostro-caudal 2.5 mm** 연장.
- 두 subdivision: anterior (aBLA) vs posterior (pBLA) — cytoarchitecture·연결성 다름 (Krettek 1978, Hintiryan 2021).

### 주요 cell type
- **D1R+ (dopamine receptor 1) 뉴런**이 주된 DA-반응성 cell ([[grove-2025-lateralized-pathway-associating-nutrients|Grove 2025]]).
- Magnocellular (medial-anterior) vs parvocellular (lateral-posterior) 구분.

### 입력
- **VTA-DA**: 특히 **CCK+ subset이 anterior BLA로 투사** (Poulin 2018, Grove 2025).
- 시상 (thalamus): emotion-relevant.
- Cortex: prefrontal, insular.
- LH (Lutas 2019): salient cue gating.

### 출력
- NAc, prefrontal cortex.
- Hypothalamus, hippocampus.
- 본 wiki 맥락에선 nutrient 가치 → 이후 행동 선택 회로로 전달.

## Anterior vs Posterior BLA 분리 ([[grove-2025-lateralized-pathway-associating-nutrients|Grove 2025]])

| 측면 | Anterior BLA | Posterior BLA |
|---|---|---|
| Nutrient (Ensure IG) DA | 강 (10–18% ΔF/F) | 약 (3%) |
| Aversive (LiCl, LPS) DA | 거의 없음 | 활성 |
| Sugar (SGLT1) DA | 강 | 거의 없음 |
| Fat (GPR40/120/CD36) DA | 강 | 거의 없음 |
| Lick phasic DA | 동등 (정상 기능) | 동등 |
| Optogenetic stim → flavor pref 학습 | **유발** | 무 |
| Optogenetic stim → food intake | 무 | 무 |
| Optogenetic stim → self-stim | 무 | 무 |

→ **anterior = nutrient appetitive, posterior = aversive interoception**.

## Lateralization ★

[[grove-2025-lateralized-pathway-associating-nutrients|Grove 2025]] 결정적 발견:
- **Mouse**: IG Ensure → left aBLA 18.2% vs right aBLA 5.3% DA.
- **Lick phasic**은 right > left (정반대) — 기술 결함 아님.
- **Human PET** (Thanarajah 2019 재분석): milkshake 후 DA 방출이 **left BLA 한정**, anterior 한정.
- **Human fMRI** (Grove 2025 신규): glucose vs water 시 left aBLA 활성.

→ **진화적으로 보존**. 신경계가 일반적으로 좌우 대칭이라 가정되는 식이 회로의 큰 예외.

가능한 origin:
- Vagus nerve 자체의 좌우 비대칭 (de Araujo 2023 bioRxiv).
- Insular cortex의 lateralized visceral 반응 (Wu 2020, Qian 2021).

임상 함의: **left anterior temporal resection** 후 Klüver-Bucy 증후군의 식이 변화 (Ghika-Schmid 1995, Anson 1993, Boronat 2013) — 이 회로 손상으로 설명 가능.

## aBLA-D1R 뉴런의 oral × gut 통합

[[grove-2025-lateralized-pathway-associating-nutrients|Grove 2025]] 2-photon imaging:
- **58%의 aBLA-D1R 뉴런이 sucrose lick에 phasic 활성**.
- 같은 뉴런 group이 **IG sucrose에 ramp 활성** (slow, 분 단위).
- Sucrose 트라이얼의 **ITI (시행 간 간격) 활성**이 lick-active 뉴런에서 증가, sucralose에서는 안 증가 → **caloric content 의존**.
- Sucrose 반응은 trial 진행 함께 stable, sucralose 반응은 감소 → **nutrient가 응답 strengthen**.

→ **Model 1 (convergent signals)** 채택: 학습이 aBLA 내부에서 일어남.

aBLA-D1R 침묵 → flavor-nutrient learning 차단, but Ensure 섭취·CTA 정상 → **specific to learning, not consumption**.

## Sequential learning model (Grove 2025 Fig. 6f)

```
환경 cue → flavor → nutrient
  (NAc DA)  (aBLA DA)
```
- **(1차)** flavor ↔ nutrient: VTA → aBLA (slow, 지연).
- **(2차)** cue ↔ flavor: VTA → NAc (fast, 즉각).
- 식이 학습은 두 단계 위계.

## 사용자 연구와의 연결

### NMPU mapping ([[kim-2024-unified-theoretical-framework-underlying-regulation]])
- **Utility (action-outcome 가치)** 회로 candidate = aBLA.
- **Motivation (effort/cue)** 회로 = NAc.
- **Need (drive)** = AgRP/SFO.
- **Pleasure (hedonic)** = oral proxy (VS 일부).

### Hijacked brain ([[lee-2025-hijacked-brain-modern-obesity-cue]])
- Cue type → NAc DA 표적 (cue exposure therapy).
- Habit type → DLS DA / NAc-shell.
- **Addiction (post-oral 보상 강박)** type → **aBLA 표적**.
- DTx 회로 분리 가능.

### GLP-1 agonist 기전
- Anti-obesity 약물 (semaglutide, tirzepatide)의 식이 선호 변화는 NAc보다 aBLA-D1R 회로 매개일 가능성.
- DMH GLP-1R cognitive satiation ([[park-2025-glucagon-like-peptide-1-and-hypothalamic]])과 평행 검증 필요.
