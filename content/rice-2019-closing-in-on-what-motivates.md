> [!takeaway] 연구 방향 관점의 핵심
> RPE 논쟁의 **새 균열**: VTA DA 뉴런 firing 과 NAc DA release 가 **분리될 수 있다**. Mohebi 2019 의 핵심 발견 — motivation ramping은 VTA firing 없이 NAc에서만 일어남 → "DA neuron firing = DA release 의 broadcast" 라는 textbook 모델 붕괴. **국소 조절** (cholinergic interneuron 등 Threlfell 2012 메커니즘)이 motivation signal 의 후보. [[hamid-2016-mesolimbic-dopamine-signals-value-work|Hamid 2016]] 의 unified value 가설을 부분적으로 도전 — phasic DA release 와 firing 의 비대칭성. NAc core vs shell, NAc vs dorsal striatum 사이 broadcast 가 아닌 **선택적 분포** — [[morales-2017-ventral-tegmental-area-cellular-heterogeneity|Morales 2017]] 의 anatomical heterogeneity 와 정합.

# Rice 2019 — Closing in on what motivates motivation (Nature N&V)

## 한 줄 요약
[[mohebi-2019-dissociable-dopamine-dynamics-learning-motivation|Mohebi 2019]] 에 대한 Nature News & Views. **DA release ≠ DA firing**: motivation 매개 ramping은 firing 없이도 일어남. 국소 조절이 핵심.

## 핵심 메시지

### Textbook DA 모델의 붕괴
> "활성 → axon 따라 → target에서 release broadcast"

이 모델은 **틀렸다**. 증거:
1. 같은 자극이 NAc core 에는 DA ↑, NAc shell·dorsal striatum 에는 변화 없음.
2. Mohebi 2019: 동기 ramping 동안 NAc release ↑, **VTA firing은 변화 없음**.
3. Howe & Dombeck 2016, Brown 2011: 무예측 보상은 NAc 에 release 일으키지만 인접 dorsal striatum 에는 없음.

### Mohebi 2019의 두 발견
| 행동 phase | VTA firing | NAc release | 해석 |
|---|---|---|---|
| Cue·reward (학습 신호) | ↑ | ↑ | Textbook RPE 작동 |
| Reward rate ramping (motivation) | **변화 없음** | ↑ | Firing-독립 release |

### 국소 조절 후보 메커니즘
- **Cholinergic interneuron** → 시냅스전 nicotinic receptor → DA release (Threlfell 2012, Cachope 2012, Surmeier & Graybiel 2012).
- VTA non-DA neuron firing 도 ramp — 국소 조절 입력 후보.
- Sulzer, Cragg, Rice 2016 review 가 종합.

## 진영 비교

| 진영 | 본 commentary 와의 관계 |
|---|---|
| **Schultz RPE** | 부분 호환 — cue·reward phasic 신호는 살아남음. |
| **Salamone effort/motivation** | 강력 지지 — motivation 신호가 firing-독립 가능. |
| **Hamid 2016 unified value** | **부분 도전** — Hamid는 NAc release 가 단일 dynamic value 신호. Mohebi는 VTA firing 없이도 release 가능 — V signal 의 일부가 국소 발생. Hamid 본문에서 "DA cell firing 과 release 의 dissociation" 인정. |
| **Morales 2017 heterogeneity** | 강력 정합 — NAc core/shell, NAc/dorsal striatum 분리 = anatomical heterogeneity 의 functional 표현. |
| **ANCCR (Namboodiri)** | 호환 — release 의 backward causal inference 도 국소 조절 메커니즘으로 자연스럽게 통합 가능. |

## 본 wiki 적용

### NMPU framework ([[kim-2024-unified-theoretical-framework-underlying-regulation]])
- **Motivation 성분**의 신경 표지자가 단일 VTA 신호가 아닐 수 있음 — NAc 국소 회로 + cholinergic interneuron + 다른 input 들의 합주.
- → NMPU 의 motivation 성분은 회로 분산 가능.

### Hijacked brain ([[lee-2025-hijacked-brain-modern-obesity-cue]])
- **Cue-evoked**: VTA firing 동반 — 학습 신호.
- **Habit context, restrained**: 국소 조절 우세 — VTA 자극으로 안 보이는 변화 가능.
- 비만에서 D2R↓ 는 NAc 국소 효과 측면에서 재해석 필요.
