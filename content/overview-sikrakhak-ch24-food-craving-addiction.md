# 식락학 Ch 24 — 음식 갈망과 중독

> 본 페이지는 사용자(최형진) 저작 교재 챕터의 위키 정리본이다. 본 챕터는 [[overview-sikrakhak-book-project|식락학 교재]] Part VI(미래 전망) 소속, 사용자 담당 4개 챕터 중 셋째.

## 한 줄 요약
음식 갈망은 배고픔의 강한 형태가 아니라 학습된 단서가 촉발하고 도파민이 유인 현저성으로 부호화하는 별개의 과정이며, 반복 노출은 보상 회로를 다섯 방향(단서 도파민 과잉·쾌락 가치 저하·습관화·강박·음성 정서 감작)으로 재편한다. '음식 중독'이 독립 진단 범주로 확립될지는 미결이지만, 그 구성 성분들은 지금도 측정·표적 가능하다.

## 챕터 구성 (절별 정리)

### 24.1 들어가며 — 갈망은 배고픔이 아니다
- **갈망 ≠ 배고픔**: 배고픔은 어떤 음식이든 해소하지만 갈망은 특정 음식을 향하고 포만 상태에서도 발생한다. AgRP 뉴런이 음식 감지만으로 즉시 꺼지는데도 접근·소비는 오히려 강해지는 해리가 신경생물학적 대응물([[concept-npy-agrp-neurons]], Chen 2015·Betley 2015).
- **3국면 분해**: craving(내적 뇌 상태) → seeking(탐색·접근) → consumption(섭취). [[lee-2019-food-craving-seeking-and|Lee 2019]]의 phase framework를 교재 언어로 재서술. 중독의 병리는 대부분 **욕구적 국면**에서 일어난다는 것이 이 절의 축.
- **측정 공백**: 인간 seeking 전용 비전산화 행동 검사 부재 → 디지털 표현형 필요성으로 연결.

### 24.2 음식 갈망의 생물학
- **24.2.1 필요와 갈망의 분리** — [[concept-need-motivation-pleasure-utility|NMPU]] 네 성분의 정렬이 깨진 상태로 갈망을 정의. 초가공 간식 = 필요 0 · 동기 高 · 즐거움 中 · 효용 陰.
- **24.2.2 단서 반응성** — [[concept-cue-reactivity]]. 인간 두개내 전극의 섬엽-덮개 음식 특이 부호화([[huang-2021-the-insulo-opercular-cortex-encodes|Huang 2021]]), 사용자 lab의 GLP-1RA × 음식 cue fMRI([[bae-2019-glucagon-like-peptide-1-receptor|Bae 2019]]), cue-potentiated feeding(Weingarten 1983).
- **24.2.3 유인-감작** — [[concept-incentive-sensitization]] 3전제 + 2025 갱신(맥락 의존·incubation·sign/goal-tracker·D2↓는 결과). 음식 확장 근거와 [[derman-2018-junk-food-enhances-conditioned-food-cup|Derman 2018]](cue approach만 선택 증폭, 비만 무관).
- **24.2.4 스트레스와 정서적 갈망** — [[concept-emotional-eating]]·[[meye-2014-feelings-about-food-the|Meye 2014]]·[[tomiyama-2019-stress-and-obesity|Tomiyama 2019]]. 그리고 [[giovanniello-2025-a-dual-pathway-architecture-for|Giovanniello 2025]]의 BLA→DMS↓ / CeA→DMS↑ 이중 경로.
- **24.2.5 갈망의 측정** — 자기보고(G-FCQ) → 암묵 측정([[soutschek-2021-opioid-antagonism-modulates-wanting|Soutschek 2021]]) → **억제 통제 부하**([[concept-inhibitory-control-demand]], 제어 개입 vs 실패 두 국면) → 회로 신호([[shivacharan-2022-pilot-study-of-responsive-nucleus|Shivacharan 2022]]·[[wu-2018-closing-the-loop-on|Wu 2018]]).
- **24.2.6 취약성은 어디서 오는가** ★신설 — 학습 양식(sign-tracker) · 발달기 각인([[shin-2023-early-adversity-promotes-binge-like-eating|Shin 2023]]: 초기 역경→LH LepR↓→성체 폭식, 환경이 방아쇠) · 유전 소인(CCKAR 다형성).

### 24.3 음식의 화학 — 무엇이 중독적 속성을 만드는가
- **당·지방 조합의 비자연성**: 자연 식품은 두 축 중 하나에만 치우침. 초가공식품만 두 축 동시 高. 상승적(supra-additive) 강화. Hall 2019 대사 병동 근거.
- **감각 특이적 포만감의 무력화**: 소금·향미 증진제·질감 교대가 식사 종료 제동을 지연.
- **단일 성분 서사 경계**: 설탕=독 프레임이 부정확한 이유를 [[hone-blanchet-2014-overlap-of-food-addiction|3모델 해리]]로 반박.
- **맛=대리 보상, 영양=1차 보상** — [[concept-primary-reward-signals]]·[[weber-2025-interoceptive-origin-reinforcement-learning|Weber 2025]]. 단맛맹 생쥐·수크랄로스·2DG 3증거.
- **두 개의 도파민** — [[tellez-2016-separate-circuitries-encode-hedonic-nutritional|Tellez 2016]](복측=맛/배측=에너지, 배측 우세) + [[thanarajah-2019-food-intake-recruits-orosensory|Thanarajah 2019]] 인체 PET(즉시 vs 지연, wanting이 지연 putamen DA와 **음**의 상관 → 갈망이 포만 신호를 억제).
- **향미-영양 학습** — [[concept-flavor-nutrient-conditioning]]. 당(SGLT1·문맥 산화) vs 지방(PPAR-α·GPR40/120, [[li-2022-gut-brain-circuits-for-fat-preference|Li 2022]]; 장은 CD36 불요). 임상: 유년기 선호의 끈질김, 수술·GLP-1 후 선호 변화.
- **속도라는 변수** — 약물동태학적 유비. 포만 호르몬 도착 시간 < 섭취 속도이면 과다 섭취가 완료된다.

### 24.4 음식 중독의 회로 — 반복 노출이 뇌를 바꾼다
- **회로 공유는 필요조건일 뿐**: 성·사회유대·음악도 같은 회로. + **보상 결핍 가설 재검토**(D2↓는 결과).
- **단서 도파민 = 취약성 표지** — [[pascoli-2026-conditioned-accumbal-dopamine-transients|Pascoli 2026]]. 선호를 예측한 것은 reward 시점이 아닌 **cue 시점** 도파민.
- **쾌락 가치 저하** ★ — [[gazit-shimoni-2025-changes-in-neurotensin-signalling-drive|Gazit Shimoni 2025]]. NAcLat→VTA neurotensin 고갈, presynaptic 병변, 과발현으로 회복. **유인-감작과의 긴장을 place preference 유지 vs 섭취 소실이라는 해리로 화해**. 개념 hub [[concept-hedonic-devaluation]].
- **목표→습관** — 결과 가치 절하 둔감. [[giovanniello-2025-a-dual-pathway-architecture-for|Giovanniello 2025]] + [[lee-2025-hijacked-brain-modern-obesity-cue|habit-context형]]. 단, [[hoang-2026-methamphetamine-potentiates-the-use-of|Hoang 2026]]의 반론(cue 통제가 결과 표상을 담음 → 자동 습관 아닌 왜곡된 의사결정 → 개입 여지).
- **처벌 저항 강박** — [[leow-2026-a-cortical-hypothalamic-neural|Leow 2026]]. rZI^GABA=기호식 특이 강박 vs TN^SST=비특이 식욕의 해리, mPFC→rZI top-down, 인간 3코호트 FC 상관.
- **음성 강화·hyperkatifeia** — [[concept-negative-reinforcement-hyperkatifeia]]·[[vendruscolo-2026-neurobiology-of-negative-reinforcement|Vendruscolo & Koob 2026]]. 3단계 순환, 확장 편도체 CRF/dynorphin, anti-stress 완충계. **쾌락 가치 저하 + 음성 강화의 결합**이 "즐겁지 않은데 멈출 수 없다"를 완성.

### 24.5 음식 중독은 실재하는가 — 개념과 논쟁
- **YFAS의 순환성**: 중독 기준을 음식에 번안해 얻은 결과로 음식이 중독적이라 결론짓는 구조. DSM-5 미채택.
- **동물 3모델 해리**([[hone-blanchet-2014-overlap-of-food-addiction|Hone-Blanchet 2014]]): 금단은 sugar·sweet-fat만, 비만은 sweet-fat만.
- **물질 중독 vs 행동 중독** + ★**끊을 수 없다는 구조적 난점**: 금주는 권할 수 있어도 금식은 권할 수 없고, 제한 자체가 유인 현저성을 키운다 → 개입 중심이 '끊기'에서 '단서·맥락 재설계'로 이동.
- **조절 상실 섭식** — [[concept-loss-of-control-eating]]. 논쟁 우회 가능·관찰 가능·예후 예측력. food preoccupation("food noise") 상류 상태([[choi-2025-brain-activity-associated-with-breakthrough|Choi 2025]]).
- **신중론** — [[stuber-2025-the-neurobiology-of-overeating|Stuber 2025]]. 결론: 이분법을 버리고 **차원적 측정**으로.
- **사회적 상류** — [[concept-food-insecurity|식품 불안정]]([[leung-2024-food-insecurity-an-emerging|Leung 2024]], 증상 21–56%↑).

### 24.6 갈망을 표적으로 하는 접근
- **5 표현형**([[lee-2025-hijacked-brain-modern-obesity-cue]]) → 표적별 개입. 단서형에 '의지' 요구는 표적 오류, 제한형에 절제 요구는 악화.
- **단서 줄이기**: 자극 통제 · 단서 노출 치료 · [[concept-affect-labeling|정서 명명]]([[tabibnia-2026-cue-labeling-reduces-cigarette-craving|Tabibnia 2026]]) · 환경 규제 · [[concept-digital-therapeutics|DTx]]([[kim-2020-multidimensional-cognitive-behavioral-therapy|Kim 2020]]).
- **약물**: 오피오이드 길항(naltrexone) vs GLP-1([[fang-2025-glucagon-like-peptide-1-medicines|Fang·Drucker 2025]] — SUD 위험 감소, 단 관찰연구 한계 + [[choi-2025-brain-activity-associated-with-breakthrough|내성/돌파]]).
- **회로 직접 개입**: tDCS/rTMS의 심부 미도달 한계 → TI·tFUS, 그리고 폐루프 [[concept-responsive-neurostimulation|rDBS]].
- Ch 25로 넘기는 경계를 본문에 명시.

### 24.7 맺음말
"갈망은 인격의 결함이 아니라 회로의 상태이며, 상태는 측정할 수 있고 측정할 수 있으면 바꿀 수 있다."

## 그림 (24.1–24.12)
3국면 / NMPU 정렬-어긋남 / 단서 반응성 회로 / 유인-감작 곡선 / 갈망-통제부하 곡선 / 자연식품 vs 초가공식품 성분 산점도 / 인체 두 도파민 시간창 / 향미-영양 조건화 실험 / 쾌락 가치 저하 회로(NAcLat→VTA NTS) / 목표→습관→강박 / 음성 강화 나선 / 5 표현형 방사형 차트.

## 위키 관점의 부가가치
이 챕터를 쓰면서 위키에 없던 **연결**이 세 개 생겼다.
1. **유인-감작 ↔ 쾌락 가치 저하의 화해 논증** — 두 이론이 각각 cue 유발 접근 행동과 자유 소비량이라는 다른 축을 본다는 정리. ([[concept-hedonic-devaluation]]·[[concept-incentive-sensitization]] 양쪽에 반영)
2. **'끊을 수 없다'는 음식 중독의 구조적 비대칭** — 물질 중독 모형을 임상에 그대로 옮길 수 없는 실무적 이유.
3. **취약성 3층 모델**(학습 양식 · 발달기 각인 · 유전) — [[shin-2023-early-adversity-promotes-binge-like-eating]]을 개인차 서사에 통합.
