> [!takeaway] 연구 방향 관점의 핵심
> **사용자 본인 lab의 이론 backbone.** 동기 행동의 4 심리 components를 명확히 분리: (1) **Need** = 예측된 결핍 알람 (e.g. ARC AgRP), (2) **Motivation** = 행동 구동력 (LH·VTA·NAc), (3) **Pleasure** = 즉각 결과 교사 (NAc·VP·IC), (4) **Utility** = 지연 결과 교사 (NTS·VMH·BLA). Wiki의 모든 회로 페이지는 이 lens로 해석. 비만의 5 maladaptive types도 framework로 매핑.

# Need-Motivation-Pleasure-Utility (NMPU) framework

## 정의
[[kim-2024-unified-theoretical-framework-underlying-regulation|Kim YB, Lee YH, Park SJ, Choi HJ. BioEssays 2024]]에서 제안된 동기 행동 통합 framework. 기존 이론들 (Hull's drive reduction, Maslow's hierarchy, Schultz RPE, Berridge's wanting/liking)이 명확히 구분 못 한 4 component를 분리.

## 4 components

### 1. Need — predicted deficiency alarm
- 예측된 결핍 (e.g. 1시간 후 저혈당 예측).
- 단순 현재 결핍 ≠ Need; **anticipation·prediction** 핵심.
- 음식 회로: [[concept-npy-agrp-neurons|ARC AgRP 뉴런]] (Kim KS 2024 Sci Adv가 Need 인코딩으로 입증).
- 다양한 needs: physiological (영양·수분·체온) vs psychological (사회·hedonic).
- Competing needs는 motivation level에서 적분 가능성.

### 2. Motivation — direct behavior driver
- Need의 누적이 Motivation 형성. 한 번 형성되면 다른 need에 흔들리지 않음.
- 두 종류:
  - **Target-dependent** (seeking + consumption — 특정 음식)
  - **Target-independent** (foraging — 일반 탐색)
- 음식 회로: [[concept-lateral-hypothalamus|LH]] 뉴런 (Lepr·Vgat·Vglut2 다양), ZI 도파민, [[concept-dopamine-reward-system|VTA DA → NAc]].
- Need ≠ Motivation: 전쟁터 군인은 need 있어도 motivation 없음; 만복 + 케이크는 need 없어도 motivation 발생.

### 3. Pleasure — immediate outcome teacher
- 즉각 (초~분) 결과 가치 (e.g. 입 안의 단맛 가치).
- Forward: 다음 motivation에 영향 (RPE).
- Reverse: 현재 motivation에 즉시 영향 (실망 → 즉시 중단).
- 음식 회로: NAc, ventral pallidum (VP), insular cortex (IC), 도파민.
- Pain/aversion은 부정적 pleasure.

### 4. Utility — delayed outcome teacher
- 지연 (시간~일) 최종 결과 가치 (e.g. 식후 혈당·영양 상태).
- Pleasure와 달리 의식 하 (unconscious) 작동 가능 — "gut feeling".
- **Pleasure decoding 알고리즘을 reshape** — 처음 쓴 커피가 학습 후 즐거워짐 (food poisoning 후 굴이 혐오).
- **Need 알고리즘도 reshape** — 새 음식 (Jello)에 처음엔 need 없으나 utility 학습 후 cue가 need 유발.
- 음식 회로: NTS (post-ingestive sugar/fat sensing), VMH (glucose), LH^HON (NEAA), BLA 도파민.

## Bidirectional cycle (Figure 3)

```
   Sensory cue/prediction
            ↓
        NEED → MOTIVATION → BEHAVIOR
                              ↓
                          IMMEDIATE OUTCOME
                              ↓
                          PLEASURE
                              │
                              ↓ teaches
                          MOTIVATIONₙ₊₁
                              ↓ delayed
                          FINAL OUTCOME
                              ↓
                          UTILITY
                              │
                              ↓ reshapes
                       PLEASURE algorithm
                       NEED algorithm
                       MOTIVATION algorithm
```

## 고전 학습 paradigm 재해석

| Paradigm                         | Framework 해석                                    |
| -------------------------------- | ----------------------------------------------- |
| Pavlovian classical conditioning | **Utility reshapes Need** (cue가 결핍 예측 신호로)      |
| Operant conditioning             | **Pleasure/Utility reshape Motivation** (행동 강화) |
| Conditioned taste aversion       | **Utility reshapes Pleasure** (단맛 → 혐오)         |

## 임상·번역적 함의

### 비만 약물 표적별 매핑 ([[lee-2025-hijacked-brain-modern-obesity-cue|Lee 2025]])
- **GLP-1RA** (semaglutide): Need + Motivation 감소 (DMH GLP-1R cognitive satiation, [[park-2025-glucagon-like-peptide-1-and-hypothalamic|Park JS 2025]]).
- **MC4R agonist** (setmelanotide): Utility 회로 downstream.
- **Bupropion-naltrexone**: Pleasure (NAc opioid).
- **Bariatric surgery**: gut → Utility 회로 reshape.

### 5 maladaptive eating types와의 매핑
- **Cue-evoked**: 외부 cue가 Need·Motivation 비정상적 활성.
- **Habit-context**: Motivation의 자동화 (goal-directed → habitual).
- **Food addiction**: Pleasure 둔감화 + Motivation 폭주.
- **Emotional eating**: 부정 감정이 Need·Motivation reshape.
- **Restrained eating**: 인지 통제가 Motivation 억제 → 역설적 disinhibition.

## 2026 시상하부 cluster 통합

REMD 2026 special issue 7편 ingest 이후 NMPU 회로 매핑 갱신:

### Need 회로 — 분자 substrate 확장
- **AgRP heterogeneity** ([[faour-2025-emerging-role-of-agrp|Faour 2025]]): ARC + AgRP^Hindbrain (Bachor 2024) + pituitary/adrenal AgRP — Need 신호의 분산.
- **Circadian Need**: SCN→DMH^Trh→ARC AgRP feed-forward (Douglass 2024 Cell Metab) — Need가 시간 anticipation까지 인코딩.
- **BNC2+/Lepr+ ARC GABA** (Tan HL 2024 Nature, Friedman lab): AgRP보다 빠른 식이 cue 반응. Need 갱신 회로 추가 노드.
- **Trh⁺/Glp1r⁺/Lepr⁺ caudal ARC 억제성 subset** (Webster 2024 RAMPANT; 위키 내 다수 페이지가 부위를 **caudal ARC**로 기록 → [[concept-arcuate-nucleus]]): liraglutide의 Need 차단 분자 회로 **후보**. 사용자 lab의 [[kim-2024-glp-1-increases-preingestive-satiation|DMH^GLP-1R]] 집단과 동일 세포인지는 미확정이며, [[heyward-2025-single-nucleus-transcriptional-and-chromatin|Heyward 2025]]는 Lepr×Glp1r 뉴런이 ARC=Trh형(74.4%)·DMH=Ebf1형(~60%)으로 갈린다고 보고한다.

### Motivation 회로 — Korotkova arbitration framework
- [[korotkova-2026-balancing-acts-lateral-hypothalamic|Korotkova 2026]]: LH가 **hunger × safety × social 3 motivational drive arbitration**.
- LH **beta oscillation + transition cells** ~2초 전 행동 전환 (Chen 2024 Nat Neurosci) — Motivation 전환의 회로 시간 동역학.
- **LepR LH** subset이 anxiety×식이 trade-off 매개 + anorexia nervosa 회로 (Figge-Schlensok 2025).
- → NMPU에서 Motivation은 **단일 hunger axis가 아닌 multi-need 통합 우선순위 결정**.

### Pleasure 회로 — POMC β-endorphin paradox
- **POMC→PVT β-endorphin→MOR → sugar appetite ON** (Minère 2025 Science): POMC가 α-MSH (satiety) + β-endorphin (orexigenic) **이원 분비**.
- → Pleasure가 동일 anorexigenic 뉴런에서 paradoxically 생산 가능. NMPU의 Pleasure axis 회로 substrate 확장.
- **CB1R-POMC = cannabinoid hyperphagia** (Koch 2015) — 같은 메커니즘.

### Utility 회로 — Microbiota·BLA·VAN 통합
- **Microbiota-hypothalamus axis** ([[barros-2026-from-diet-to-hypothalamic-dysfunction|Barros 2026]]): SCFA·LPS·bile acid가 Utility 신호의 분자 매개자.
- ARC acetate → POMC GPR43-AMPK 회로 = post-ingestive Utility의 새 회로.
- TGR5 시상하부가 Utility-Pleasure decoding 매개 (Castellanos-Jankiewicz 2021).
- **VAN neuropod → vagal afferent** (millisecond) = Utility의 빠른 입력 (이미 [[de-lartigue-2026-critical-role-gut-brain-signalling|de Lartigue 2026]]에서 정립).

### Algorithm reshape — POMC 정체성 가소성
- **Ghost POMC** ([[concept-ghost-pomc-neurons|Leon 2024 Nat Commun]], Quarta lab): 비만 환경에서 POMC functional identity 자체가 atypical로 shift. 
- → NMPU의 **알고리즘 reshape (Utility reshapes Pleasure·Need algorithm)** 의 분자 substrate 후보.
- 비만 환자의 회로 가소성이 단순 strength 변화가 아닌 **cell identity transformation** 수준.

### 발달 가소성 — 모체 비만 programming
- [[freire-agulleiro-2026-early-life-programming-of|Freire-Agulleiro 2026]]: 모체 비만이 자손 Need:Motivation balance를 sex-specific하게 reshape.
- Postnatal leptin surge blunting → ARC projection 손상 → Need 신호 default 강화.
- VMH(SF1/BDNF)→LH connectivity 강화 → Motivation hyperactive predisposition.
- → NMPU의 **알고리즘이 발달 단계에서 한번 calibrate되면 lifelong 영향** 임을 시사.

### Single-cell atlas era
- **HypoMap mouse + 인간 atlas** ([[concept-hypomap|Tadross 2025 Nature]]): NMPU 4 component를 cluster-level resolution으로 매핑 가능.
- **인간 POMC = LepR + GLP1R 공발현** — 사용자 lab의 NMPU framework 인간 번역 분자 정당성.

## 외부 framework와의 정렬 (2025) ★

[[weber-2025-interoceptive-origin-reinforcement-learning|Weber, Yee, Small, Petzschner 2025 Trends Cogn Sci]]가 RL framework를 interoception 기반으로 재정의 — NMPU와 핵심적으로 호환:

| NMPU                            | Weber 2025 RL framework                                                      |
| ------------------------------- | ---------------------------------------------------------------------------- |
| **Need** (predicted deficiency) | Drive (anticipatory, AgRP/SFO encoding **expected future state**)            |
| **Motivation**                  | Secondary reward + effort (NAc DA dynamics)                                  |
| **Pleasure**                    | Proxy reward (oral taste, "early affective draft")                           |
| **Utility**                     | Primary reward (post-oral interoceptive, [[concept-primary-reward-signals]]) |

→ Weber framework의 **state-driven (water) vs event-driven (sugar/fat)** 구분도 NMPU 안에 흡수 가능 — Utility의 두 sub-type.

[[knight-liberles-2025-interoception|Knight & Liberles 2025]] editorial의 **저자 약력란**에 실린 anticipatory homeostasis 진술(homeostatic neuron이 sensory cue로 bodily change를 **anticipate**)은 NMPU의 Need definition과 **개념적으로 정합**하다(위키의 해석 — editorial 본문은 NMPU를 언급하지 않는다).

→ **사용자 lab의 NMPU framework가 2025 frontier가 도달한 결론과 정렬**. NMPU는 4-component 분리·bidirectional cycle·algorithm reshape 등에서 더 ambitious. RL 분야에 NMPU를 push할 timing.

회로 매핑 갱신:
- **Utility** (지연 outcome)의 분자 회로:
  - State-driven (water): LH GABAergic → VTA DA ([[grove-2022-dopamine-subsystems-track-internal|Grove 2022]]).
  - Event-driven (sugar/fat): VTA-DA-CCK → **left aBLA D1R** ([[grove-2025-lateralized-pathway-associating-nutrients|Grove 2025]], [[concept-basolateral-amygdala]]).
- 이로써 NMPU의 Utility hub가 **NTS, VMH, BLA, LH-VTA** 4개 분리.
