# Maternal programming of hypothalamic circuits

## DoHAD framework
- Pre-conception → lactation 어떤 단계든 lifelong 위험 결정.
- Pre-pregnancy obesity, gestational weight gain, GDM, maternal undernutrition 모두 contribute.
- Epigenetic·hormonal·inflammatory·neurovascular pathway 통합.

## 6 매개 메커니즘 ([[freire-agulleiro-2026-early-life-programming-of|Freire-Agulleiro 2026]])

1. **Neuroinflammation** — IL-6·IL-1β·TNFα → astrocyte proliferation.
2. **Fatty acid · ER stress** — SFA → ATF4·GRP78 ↑ in POMC·AgRP (P10).
3. **BBB · tanycyte** — vimentin·morphology 손상.
4. **Leptin signaling** — postnatal surge (P0–P14) blunting → projection 미발달.
5. **Insulin signaling** — fetal hyperinsulinemia → POMC PVN connectivity 손상.
6. **Epigenetics** — *Pomc* hypermethylation, miR-505-5p ↑.

## 영향 회로
- **ARC melanocortin**: NPY:POMC ratio ↑, Ascl1 ↓, POMC projection ↓.
- **PVN**: OXT ↓, CRH ↑ (DMV projection ↓ → "stressed vagal"), **MC4R → hypertension** ★.
- **LH**: VMH(SF1/BDNF) → LH connectivity 강화, orexin leptin sensitivity ↑.
- **Kisspeptin (Kiss1 hypermethylation)** → 생식 axis 손상 (조숙증).
- **Autonomic**: WAT TH+ fiber ↓, pancreatic vagal ↓, fetal HRV ↓.

## Sex dimorphism (★)
- Pre-pregnancy obesity → **male 자손이 우세하게 영향** (body weight·adiposity).
- Insulin in dam P4–16 → α-MSH·AgRP innervation male only 손상.
- Pomc hypermethylation pattern sex × postnatal diet 의존.
- Female이 chemogenetic POMC stress manipulation resilient.

## Critical window
- **Pre-pregnancy** (maternal BMI 결정).
- **Gestational** (placental nutrient·hormone transfer).
- **Lactational** (postnatal leptin surge P0–P14 in mouse, 인간은 prenatal).
- 인간: prenatal 가장 결정적 (시상하부 maturation timeline).

## Rescue / intervention path
- **TUDCA (chemical chaperone)**: ER stress 차단 → POMC projection 복원 (Park 2020).
- **4-phenylbutyrate**: 자손 metabolic phenotype 개선.
- **Melatonin** (obese dam): IL ↑·NPY/POMC 정상화.
- **Cross-fostering to lean mother**: BBB·tanycyte 회복 — postnatal modifiable.
- **Maternal exercise**: miR-505-5p 정상화.
- **GLP-1 agonist 임신 중**: 안전성 미해명 — 핵심 미래 issue.

## 임상 / 모체 보호
- **Pre-pregnancy BMI normalization** = 가장 강력한 intervention.
- GDM screening·관리.
- 모체 식이 omega-3·fiber 권장.
- Bariatric surgery 후 임신 자손 결과 — 연구 진행 중.

## 사용자 lab 함의
- 사용자 lab의 임상 비만 환자 중 **preconception 인자 평가** = 가족력 modulation.
- Tx 시 **임신 가능 여성** 안전성 (GLP-1·setmelanotide).
- 사용자 lab + 서울대 산부인과·소아청소년과 협업 path.
- **POMC plasticity** ([[concept-ghost-pomc-neurons|Ghost POMC]] + maternal programming) = 같은 회로의 두 측면.
