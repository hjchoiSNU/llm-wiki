# Oral Small-Molecule GLP-1RA Aleniglipron — ACCESS phase 2b (Rosenstock 2026)

## 한 줄 요약
경구 1일 1회 소분자 GLP-1RA **aleniglipron(GSBR-1290, Structure Therapeutics)**의 phase 2b, 이중맹검·위약대조 시험. 비만/과체중 성인 230명, 36주. 위약-보정 체중 변화 **−8.2%(45 mg)·−9.8%(90 mg)·−11.3%(120 mg)** (모두 P<0.0001), 정체기 없음.

## 핵심 내용
- **약물**: aleniglipron — 고선택성 경구 소분자 GLP-1RA, 1일 1회. 4주마다 45/90/120 mg로 적정.
- **설계**: ACCESS phase 2b, n=230 (45 mg 45 / 90 mg 65 / 120 mg 64 / 위약 56), 미국 38개소. 평균 BMI 39.5, 54% 여성. 공개표지연장(OLE) 포함. NCT06693843.
- **1차(36주)**: 위약-보정 체중 변화율.
  - 위약-보정: **−8.2% / −9.8% / −11.3%** (P<0.0001 전 용량).
  - efficacy estimand LS mean: −9.0% / −10.7% / −12.1% vs 위약 −0.8%.
- **반응자(120 mg)**: ≥5% 86%, ≥10% 70%, ≥15% 38% (위약 23/7/1%).
- **연장(OLE 중간분석, 중앙값 20주)**: 추가 감량 지속(총 −13.3~−16.2%); 위약→aleniglipron 전환군도 감량.
- **안전성**: 위장관 부작용 경도~중등도, 시간 경과로 감소; **용량 중단 후 재개 시 구토 거의 재발 안 함**. 치료 관련 중단 10.4%, **약물유발 간손상 없음**.
- **결론**: 임상적으로 의미있는 −11.3% 감량 + GLP-1RA class 수준 내약성 → phase 3(2.5 mg 시작) 지지.

## 사용자 lab 관점
- **경구 소분자 paradigm 강화**: [[davies-2026-elecoglipron-an-oral-small|elecoglipron(VISTA)]]과 나란히 경구 GLP-1RA의 효능·내약성 입증.
- **내약성 회로**: 복용 중단/재개에도 구토가 재발하지 않는 적응 현상 → 후뇌 욕지기 회로 적응 연구 단서([[gao-2026-semaglutide-drives-weight-loss-through]]).
- **정체기 없음**: 36주 이중맹검 + OLE 중간분석(중앙값 20주)까지 감량 궤적이 꺾이지 않음 = **투약 중 약효 지속**의 증거. ⚠️ set-point 재설정의 증거로 읽지 말 것 — 본 시험은 **중단 후 추적을 보고하지 않았고**, 방어되는 지방량의 재설정 여부는 중단 후 체중 궤적으로만 검증된다. 위키의 재증가 근거는 오히려 반대 방향이다([[concept-weight-regain-defended-adiposity]]: SURMOUNT-4 중단 후 52주간 +14.0%, 세마글루타이드 중단 후 12주 내 71.4% 재증가).
